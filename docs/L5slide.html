5.1 AFT模型

AFT模型（Accelerated Failure Time Model）假设：
> 协变量通过加速或减缓“时间流逝”的方式影响个体的生存时间。

5.1 AFT模型：基本思想

数学形式为：

\[ \log(T) = \mu + X^\top \beta + \sigma \epsilon \]

  • \[ T \]：生存时间
  • \[ X \]：协变量向量
  • \[ \beta \]：回归系数
  • \[ \epsilon \]：随机误差项，服从某种分布（决定模型类型）
  • \[ \mu \]：截距项
  • \[ \sigma \]：尺度参数

这是一个对数-线性回归模型，对数生存时间服从线性模型。

5.1 AFT模型： 常见的分布类型

模型类型 \[ \epsilon \] 分布 生存时间分布
Exponential Gumbel (固定 scale) 指数分布
Weibull Extreme value (EV) Weibull分布
Log-normal 正态分布 对数正态分布
Log-logistic Logistic分布 对数逻辑分布

你可以使用 survreg() 拟合这些模型。

5.1 AFT模型： 与Cox比例风险模型的比较

维度 AFT模型 PH模型（Cox）
作用方式 建模 \[ \log(T) \] 建模风险函数 \[ h(t|X) \]
参数解释 加速或减缓生存时间的倍数 改变风险函数的比例
分布设定 需要指定误差分布 无需指定（半参数）
拟合方法 极大似然 局部偏似然
可预测生存时间 ✅ 是 ❌ 否（只能估风险）

5.1 R语法结构：AFT模型

library(survival)

5.2 Weibull模型

  • 当 \[ \beta_j > 0 \]：协变量 \[ x_j \] 延长生存时间
  • 当 \[ \beta_j < 0 \]：协变量 \[ x_j \] 缩短生存时间

AFT模型回答的问题： > “某治疗是否能延长生存时间？”

“某风险因素是否让病人更快死亡？”

5.2 平滑生存曲线

虽然 Kaplan-Meier 方法功能强大，使用广泛，但它主要用于描述性分析。

🟧 局限性：

  • KM 曲线是阶梯状，类似直方图
  • 难以进行协变量调整与推论分析

🟩 Weibull 模型的优势：

  • 提供连续、光滑的生存曲线
  • 类似于用线性模型替代直方图
  • 假设生存时间服从 Weibull 分布，这个假设在许多应用中效果良好

5.2 R代码： 拟合 Weibull 模型及绘制平滑生存曲线

使用 survreg() 函数（来自 survival 包）即可拟合 Weibull 模型：

survreg(Surv(time, status) ~ 1, dist = "weibull")

5.2 计算 Weibull 模型的生存曲线（回归模型）

🎯 关键函数：survreg()
Weibull 模型由 survreg() 函数拟合，其语法与 survfit() 相似：

survreg(Surv(time, status) ~ 1, dist = "weibull")

📌 注意：

survfit() 是 Kaplan-Meier 的非参数估计方法；

survreg() 是 AFT 框架下的参数回归方法，要求指定分布（如 “weibull”）；

“fit” 用于描述性分析；“reg” 用于推论和建模。

5.2 从 Weibull 模型中计算生存时间指标

我们通常希望从拟合的模型中得到某些关键的生存时间点。例如，计算 90% 患者仍然生存时所对应的时间。

预测 90% 的患者仍存活的时间

predict(model, type = “quantile”, p = 1 - 0.9) type = “quantile”：要求返回分位数；

p = 1 - 0.9 = 0.1 表示死亡概率为 10%，即生存概率为 90%；

返回值即为生存概率为 90% 时的时间点。

此时模型输出的时间约为 384 天，表示 90% 的患者在 384 天之前仍存活。

注意：若模型中有协变量，则可通过 newdata = 指定不同个体，得出个性化预测。

5.2 绘制 Weibull 模型预测的生存曲线

为了获得一条平滑的生存曲线，我们可以预测多个分位数，并计算其对应的生存概率。

构造一组分位数（从 99% 到 1%）

p_seq <- seq(0.99, 0.01, by = -0.01)

利用模型预测这些分位数对应的时间点

t_pred <- predict(model, type = “quantile”, p = p_seq)

构建用于可视化的生存数据框

surv_plot_data <- data.frame( time = t_pred, surv = 1 - p_seq # 分位数转换为生存概率 S(t) )

这个数据框 surv_plot_data 包含一系列 (time, S(t)) 点，可用于 ggplot2 绘制平滑生存曲线。

绘图示例（将在下一讲中详解）：

library(ggplot2)

ggplot(surv_plot_data, aes(x = time, y = surv)) + geom_line(size = 1.2) + labs(title = “Weibull 模型预测的生存曲线”, x = “时间（天）”, y = “生存概率 S(t)”) + theme_minimal()

4.3 Cox模型的估计: 语法结构

R语言中，Cox比例风险模型的核心函数是 survival::coxph()，它用于拟合 Cox 模型。

  • coxph(Surv(time, status) ~ covariates, data = dataset)

  • Surv(time, status) 创建生存对象，包含生存时间和生存状态。

  • covariates 是一个或多个解释变量，可以是连续型或分类型。
