6.1 竞争风险模型简介

  • 竞争风险分析（Competing Risks Analysis）是生存分析的分支，处理目标事件受其他“竞争事件”干扰的情况，后者可能先发生并阻止目标事件。

  • 示例：研究癌症患者因病死亡时，其他原因（如心血管病）死亡为竞争事件。

为什么需要竞争风险分析？

  • 传统生存分析（如Kaplan-Meier、Cox模型）假设删失是独立的，与目标事件风险无关。

  • 现实中，竞争事件（如其他原因死亡）会阻止目标事件，导致删失不独立，传统方法可能低估风险。

应用场景

  • 医学：分析特定疾病死亡概率，考虑其他死亡原因。

  • 工程：分析设备特定故障失效时间，考虑其他故障。

  • 社会学：分析失业人员找到工作的概率，竞争事件如退出劳动力市场。

竞争风险分析核心概念

竞争风险分析通过累积发生概率（Cumulative Incidence Function, CIF）或亚分布风险（Subdistribution Hazard）来估计目标事件的概率。

  • 累积发生概率（Cumulative Incidence Function, CIF）: 在某时间点前，目标事件发生的概率，考虑了竞争事件的影响。

  • 亚分布风险：针对目标事件的特定风险函数，用于建模协变量对 CIF 的影响。

Fine-Gray模型：一种常用的竞争风险回归模型，基于亚分布风险，估计协变量对目标事件累积发生概率的影响。

Gray 检验：比较不同组的CIF，适用于竞争风险。

竞争风险模型数学框架

累积发生概率（CIF） 对于目标事件 \(k\) \(，CIF 定义为：\)\(CIF_k(t) = P(T \leq t, \text{事件类型} = k)\)$ 其中 $ T $ 是事件发生时间，CIF 考虑了所有竞争事件的发生概率。

Fine-Gray 模型

Fine-Gray 模型基于亚分布风险函数，假设协变量对目标事件的亚分布风险有比例效应： \[h_k(t | X) = h_{k0}(t) \exp(\beta_1 X_1 + \beta_2 X_2 + \dots + \beta_p X_p)\] 其中：

$ h_k(t | X) $：目标事件 $ k $ 的亚分布风险。

$ h_{k0}(t) $：基线亚分布风险。

$ _i $：协变量 $ X_i $ 的回归系数，解释变量对 CIF 的影响

6.3.3 CIF曲线

竞争风险累积发生概率（Cumulative Incidence Function, CIF）曲线: 直观比较各结局的累积风险随时间的变化

Code 
# 绘制竞争风险累积发生概率（Cumulative Incidence Function, CIF）曲线

survminer::ggcompetingrisks(
  fit = survfit(Surv(time, status) ~ 1, data = Melanoma),
  data = Melanoma,
  palette = "jco"
)

  • 蓝色：未发生事件。

  • 黄色：事件 1。

  • 灰色：事件 2。

  • 蓝色面积 = 1 - CIF(1) - CIF(2)。

  • 每个时间点，黄色和灰色部分的高度叠加，代表“某事件已发生”的总比例。

  • 蓝色区域 = 1 − CIF(事件1) − CIF(事件2) 即尚未发生任何事件的比例。

  • 随着时间推移，蓝色面积减少，说明越来越多个体发生了某种类型的事件。

  • 展示了在存在两种竞争事件的前提下，不同事件在随访期间的累积发生概率如何随时间上升，同时显示有多少个体仍未发生任何事件。

6.3.6 估计竞争风险回归

Fine-Gray 模型估计结果

Code 
# 竞争风险回归，分析 sex 和 age 对结局的影响
tidycmprsk::crr(Surv(time, status) ~ sex + age, data = Melanoma)

Variable   Coef    SE      HR     95% CI       p-value    
sex        0.588   0.272   1.80   1.06, 3.07   0.030      
age        0.013   0.009   1.01   0.99, 1.03   0.18

  • sex: HR = 1.80, p-value = 0.03 解释：与参考组相比（sex=0为女性，sex=1为男性），男性发生type 1结局（因黑色素瘤死亡）的亚分风险比为1.80，即男性发生该结局的风险是女性的1.8倍。p值小于0.05，说明性别的影响具有统计学意义。

  • age: HR = 1.01, p-value = 0.18 每增加一岁，type 1结局的亚分风险比增加1%（1.01倍），但p值为0.18，不具有统计学显著性（即年龄对type 1结局风险的影响不显著）。这可能因年龄范围较窄或竞争事件掩盖了效应。

Fine-Gray 竞争风险回归模型（subdistribution hazard model）

Fine-Gray 竞争风险回归模型型的估计结果： \[h_1(t | X) = h_{01}(t) \exp\left(0.588 \cdot \text{sex} + 0.013 \cdot \text{age}\right)\] 变量定义

sex：通常编码为 0（男性）或 1（女性），需确认 Melanoma 数据中的具体编码。若 sex = 0 为参考组（女性），则 $ = 1 $ 表示男性。

age：连续变量，表示年龄（单位：年）。

$ h_{01}(t) $：基线子分布危险率，依赖于时间 $ t $ 和数据，但 crr() 不直接提供其解析形式，通常通过非参数方法估计。

表格化输出Fine-Gray 估计结果

Code 
# 竞争风险回归结果整理为回归表（exp=TRUE 输出HR及置信区间）
tidycmprsk::crr(Surv(time, status) ~ sex + age, data = Melanoma) %>% 
  tbl_regression(exp = TRUE)

6.3.7 对比竞争风险回归和Cox回归

  • Fine-Gray回归（SHR）： 评估变量对实际累计发生概率（CIF）的影响，适合临床决策。

  • Cox回归（HR）： 评估变量对即时发病风险的影响，适合机制探索。

  • 建议： 两者结合分析，结果更全面。

Code 
# 竞争风险回归（Fine-Gray模型）
fit_fg <- tidycmprsk::crr(Surv(time, status) ~ sex + age, data = Melanoma)
tbl_fg <- tbl_regression(fit_fg, exp = TRUE, label = list(sex = "Sex", age = "Age")) %>%
  modify_header(label = "**变量**") %>%
  modify_caption("**Fine-Gray 竞争风险回归**")

# Cox回归
fit_cox <- coxph(Surv(time, ifelse(status == 1, 1, 0)) ~ sex + age, data = Melanoma)
tbl_cox <- tbl_regression(fit_cox, exp = TRUE, label = list(sex = "Sex", age = "Age")) %>%
  modify_header(label = "**变量**") %>%
  modify_caption("**Cox 比例风险模型**")

tbl_merge(
  tbls = list(tbl_fg, tbl_cox),
  tab_spanner = c("**Fine-Gray 竞争风险回归**", "**Cox 比例风险模型**")
)

  • 性别（男性）是影响目标事件（如因黑色素瘤死亡）风险的独立因素，无论是否考虑竞争风险；

  • 而年龄虽然在Cox模型下接近显著，但在Fine-Gray模型下未见统计学意义，提示在存在竞争风险时年龄的影响被削弱。

总结

  • 竞争风险简介：解决目标事件受竞争事件干扰的生存分析，适用于医疗、工程等领域。

  • 核心概念：CIF 衡量发生概率，Fine-Gray 模型和 Gray 检验分析影响。

  • 工具：tidycmprsk 提供 cuminc 和 crr，优于 cmprsk。

  • 方法对比：Fine-Gray (SHR) 适合预后，Cox (HR) 适合机制研究，互为补充。
