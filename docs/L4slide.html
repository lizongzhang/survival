4.1 Cox模型简介

4.1.1 Cox比例风险模型设定

  • Cox比例风险模型(Cox Proportional Hazards Model,

  • 简称CoxPH), 用于分析生存时间（或“事件发生时间”）与影响因素（协变量）之间的关系。

  • Cox模型围绕风险函数建模，是因为风险函数能自然处理删失数据、便于推导似然函数、模型解释直观、无需假定基线风险\(h_0(t)\)分布。

模型表达式

\[ h(t|X) = h_0(t) \exp(\beta^T X) \]

\[ h(t | X) = h_0(t) \cdot \exp(\beta_1 x_1 + \beta_2 x_2 + \dots + \beta_p x_p) \] \[ \log h(t|X) = \log h_0(t) + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_p x_p \]

  • \(h(t|X)\)：时刻 \(t\) 的瞬时风险(hazard rate)

  • \(h_0(t)\)：基线风险函数

  • \(x_1, x_2, \ldots, x_p\)：协变量(解释变量)

  • \(\beta\)代表该变量每增加一个单位时，\(\log\)风险比的改变。

  • 对于预测变量，\(\exp(\beta)\)为“风险比”（Hazard Ratio）：

    • \(\beta > 0\)：风险增加

    • \(\beta < 0\)：风险降低

4.1.2 风险比例假设 Proportional Hazards Assumption

  • 不同协变量组之间的风险比（Hazard Ratio, HR）在整个随访期间是恒定的，不随时间变化。

风险比例的数学表达式

Cox模型的风险函数公式：

\[ h(t|X) = h_0(t)\exp(\beta^T X) \]

  • 对于两个不同的协变量组\(X_1\)和\(X_2\)，它们的风险比为： \[ \frac{h(t|X_1)}{h(t|X_2)} = \frac{h_0(t)\exp(\beta^T X_1)}{h_0(t)\exp(\beta^T X_2)} = \exp\left(\beta^T(X_1 - X_2)\right) \]

  • 这个比值与时间\(t\)无关，只与协变量差异有关。

风险比例假设的直观理解

  • 举例：
    • 假如男性和女性的风险比为2，无论研究到第1年还是第5年，男性的风险率始终是女性的2倍。
  • 换句话说，不同组的风险曲线“始终相隔一条固定倍数的距离”，不会随时间交叉或逐渐靠近/远离。

风险比例假设不成立的情况

  • 风险比随时间变化（如药物疗效消退、不同组风险曲线交叉），则不满足风险比例假设，CoxPH模型结果可能不可靠。

  • 可考虑使用时间依赖协变量模型或分层Cox模型等替代方法。

检验风险比例假设的方法

  • Schoenfeld残差检验

4.1.3 Cox模型中如何计算生存函数？

第1步：生存函数与风险函数的关系(参见L1讲义)

\[ S(t|X) = \exp\left(-\int_0^t h(u|X) du\right) \]

第2步：带入Cox模型的风险函数

将 \(h(t|X) = h_0(t) \exp(\beta^T X)\) 代入上式：

\[ S(t|X) = \exp\left(-\int_0^t h_0(u) \exp(\beta^T X) du\right) \]

第3步：分离协变量与时间

注意 \(\exp(\beta^T X)\) 对于特定个体是常数，可以提到积分符号外：

\[ S(t|X) = \exp\left(-\exp(\beta^T X) \int_0^t h_0(u) du\right) \]

第4步：引入基线生存函数 \(S_0(t)\)

定义基线生存函数（当 \(X=0\)）：

\[ S_0(t) = \exp\left(-\int_0^t h_0(u) du\right) \]

第5步：生存函数的最终表达式

将基线生存函数带入，得到：

\[ S(t|X) = [S_0(t)]^{\exp(\beta^T X)} = \exp\left( -\exp(\beta^T X) \int_0^t h_0(u) du \right) \]

  • 模型估计形式：

    • 使用部分似然函数（Partial Likelihood）估计回归系数 \(\beta\)

    • 基线生存函数 \(S_0(t)\) 用非参数法估计

4.1.4 Cox模型与其他生存分析模型比较

4.2 Cox建模的数据要求

检查点 推荐标准
是否有足够事件？ 每个解释变量 (predictor) 至少需要 10 个发生的事件（status = 1）
样本删失比例不宜过高 status = 1 的比例 ≥ 30% 最佳
变量是否有严重缺失？ 不推荐变量缺失率 > 15%
是否满足比例风险？ 拟合后需检验（如 Schoenfeld 残差）

Vittinghoff, E., & McCulloch, C. E. (2007). Relaxing the rule of ten events per variable in logistic and Cox regression. American Journal of Epidemiology.

4.3 Cox模型的估计和检验

4.3.1 数据说明

  • inst：医疗机构编号

  • time：生存时间（天）

  • status：生存状态。1 = 删失（censored），2 = 死亡（event

  • age：年龄（岁）

  • sex：性别, 1 = 男，2 = 女

  • ph.ecog：ECOG（医生评估的体能评分），评分从 0（无症状）到 4（卧床）

  • ph.karno：医生评估Karnofsky评分, 0–100, 数值越高表示功能越好

  • pat.karno：患者评估Karnofsky评分

  • meal.cal：每餐摄入热量 (calories)

  • wt.loss：最近 6个月内体重下降的数值(磅)

Loprinzi, Charles Lawrence, et al. “Prospective evaluation of prognostic variables from patient-completed questionnaires. North Central Cancer Treatment Group.” Journal of Clinical Oncology 12.3 (1994): 601–607.

4.3.4 Cox模型的估计

语法结构

R语言中，Cox比例风险模型的核心函数是 survival::coxph()，它用于拟合 Cox 模型。

  • coxph(Surv(time, status) ~ covariates, data = dataset)

  • Surv(time, status) 创建生存对象，包含生存时间和生存状态。

  • covariates 是一个或多个解释变量，可以是连续型或分类型。

Cox模型系数的解读

Cox模型的数学形式如下：

\[ \log h(t|x) = \log h_0(t) + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_p x_p \]

\(\beta\)，表示每个解释变量 \(x_p\) 对对数风险函数 \(\log h(t|x)\) 的线性影响。即 \(x_p\) 增加1个单位，\(\log h(t|x)\) 增加 \(\beta_p\)。

\[ h(t | X) = h_0(t) \cdot \exp(\beta_1 x_1 + \beta_2 x_2 + \dots + \beta_p x_p) \]

\(exp(\beta)\)，表示 \(x_p\)增加1个单位时，事件发生的风险(即刻发生该事件的瞬时速率) \(h(t|x)\)的相对变化倍数。 \(\exp(\beta_p)>1\) 表示风险增加, \(\exp(\beta_p) < 1\) 表示风险降低。

\[ Hazard \space Ratio = \exp(\beta_p) \]

正系数 → 风险增加, 负系数 → 风险降低

4.3.5 检验风险比例假定

Code 
library(survival)
data(cancer, package = "survival")

lung <- lung %>%
  mutate(
    status = recode(status, `1` = 0, `2` = 1),   
    female = recode(sex, `1` = 0, `2` = 1)
  )

fit <- coxph(Surv(time, status) ~ female + age + wt.loss + ph.ecog + ph.karno, data = lung) 

# 检验风险比例假定--Schoenfeld残差检验
fit %>% cox.zph()
         chisq df     p
female   2.059  1 0.151
age      0.186  1 0.666
wt.loss  0.110  1 0.740
ph.ecog  1.359  1 0.244
ph.karno 4.916  1 0.027
GLOBAL   7.174  5 0.208

  • chisq：Schoenfeld残差检验的卡方统计量, df：自由度

  • 对于每个变量及全局（GLOBAL），p值越大于0.05，说明风险比例假定越成立。

  • GLOBAL也叫“全局检验”。它的p值反映了所有协变量加在一起时，模型整体是满足风险比例假定。

  • 如果GLOBAL的p值较大（通常>0.05），说明整体上Cox模型的风险比例假定是成立的。

# Schoenfeld残差的可视化
# 平滑曲线接近水平，无明显上升或下降趋势, 风险比例假设成立。
fit %>% 
  cox.zph() %>% 
  plot(var = "female")
  • Schoenfeld残差图若平滑曲线接近水平，说明风险比随时间不变，PH假定成立；若明显有趋势，则PH假定可能不成立。
Code

4.4.1 生存曲线

生存曲线（Survival Curve）是生存分析中用来描述某一群体或个体在随访时间内“存活”概率随时间变化的图形。

基线生存曲线: 所有协变量取0时，个体在各时间点的生存概率。

\[ S_0(t) = \exp\left(-\int_0^t h_0(u) du\right) \]

基线生存曲线

Code 
# 定义基线个体（所有协变量设为 0 ）

  female = 0,
  age = 0,  
  wt.loss = 0,
  ph.ecog = 0,
  ph.karno = 0
)

sf_base <- survfit(fit, newdata = newdata)

# 绘制基线生存曲线

  labs(
    title = "Cox模型基线生存曲线",
    x = "时间（天）",
    y = "生存概率"
  ) +
  theme_minimal()

高低风险组生存曲线

使用 Cox 比例风险模型对病人进行风险分层后，高低风险组的Kaplan-Meier 生存曲线。你使用了 predict(fit, type = “lp”) 计算每位患者的风险评分（线性预测值），然后基于中位数将样本分为高风险组与低风险组。

在Cox回归生存分析中，高风险组（High risk group）是指： 对每个患者（样本），根据Cox回归模型计算出其风险评分（risk score，通常就是线性预测得分：risk_score = β1×X1 + β2×X2 + … + βn×Xn）。

然后, 以风险评分的中位数为阈值，大于中位数的分为“高风险组”，小于等于中位数的分为“低风险组”。

显著生存差异：红色曲线（高风险组）与蓝色曲线（低风险组）之间差距明显，p 值远小于 0.05，说明模型能有效区分不同风险个体的生存预后。

模型有较好判别力：高低风险组的生存曲线没有交叉，且间距较大，说明 Cox 模型捕捉到了关键影响因素。

Code 
library(survival)
library(survminer)

# 步骤1: 计算风险评分
fit <- coxph(Surv(time, status) ~ female + age + wt.loss + ph.ecog,
             data = lung,
             na.action = na.exclude)  # 保留原始行号结构

lung$risk_score <- predict(fit, type = "lp", na.action = na.exclude)

# 步骤2: 分组（以中位数为界）
lung$risk_group <- ifelse(lung$risk_score > median(lung$risk_score, 
                                                   na.rm = TRUE), 
                          "High risk", "Low risk")

# 步骤3: 拟合分组生存曲线
fit_group <- survfit(Surv(time, status) ~ risk_group, 
                     data = lung)

# 步骤4: 绘制生存曲线
ggsurvplot(
  fit_group,
  data = lung,
  pval = TRUE,                  # 显示log-rank检验p值
  legend.title = "Risk Group",
  legend.labs = c("High risk", "Low risk"),
  palette = c("#E41A1C", "#377EB8"),  # 红、蓝
  xlab = "时间（天）",
  ylab = "生存概率",
  title = "高低风险组生存曲线"
)

4.4.2 累积风险曲线

累积风险\(H(t)\) 表示从研究开始（时间 $ t = 0 $）到时间 $ t $ 为止，个体经历事件（例如死亡、疾病发作、设备故障等）的总风险。

累积风险 $ H(t) $ 是风险函数 $ h(t) $（也叫瞬时风险率，hazard rate）在时间区间 \([0, t]\) 上的积分。

\(H(t)=\int_0^t h(u)du\)

风险函数\(h(t)\)表示在时间\(t\) 时刻，条件于个体仍存活的情况下，单位时间内发生事件的概率。

在实际应用中，累积风险\(H(t)\)与生存函数 \(S(t)\)（即到时间\(t\) 仍存活的概率）有以下关系：

\(H(t)=-\log (S(t))\)

生存函数\(S(t) = \exp(-H(t))\)，表示生存概率随着累积风险的增加而下降。

Code 
fit <- coxph(Surv(time, status) ~ female + age + wt.loss + ph.ecog + ph.karno, data = lung) 


survfit(fit) %>% 
  ggsurvfit(type = "cumhaz")

累积风险曲线特征

  • 累计危险越高，生存概率越低。

  • 曲线陡峭上升，说明某一时期风险骤增（如手术后早期死亡风险高）’

  • 曲线逐渐平缓，说明风险趋于稳定或事件发生减少。

4.4.4 互补对数-对数图cloglog plot

互补对数-对数图（complementary log-log plot, cloglog plot）: 检查比例风险假设。

在Cox比例风险模型中，核心假设就是：不同组之间的风险函数（hazard functions）是成比例的。

如果不同组之间的风险函数是成比例的（满足Cox模型的比例风险假设），那么这些组的互补对数-对数曲线将是大致平行的直线。

如果曲线不平行或交叉，说明比例风险假设可能不成立。

4.4.5 列线图rms::nomogram()

列线图（Nomogram）是将回归模型（如Cox、Logistic回归）转化为可视化评分表的工具，用于临床个体化预测。它把每个变量的取值转换为分数，然后通过总分推算某一结局（如1年生存率）。

把模型变成“分数表”，你只需查分、加分、对照即可得到个体预测概率。

一张列线图的结构一般包括： - 最上方一行：Points（得分）

  • 这是一把“定标尺”，用于查每个变量取值对应的分数。

  • 中间多行：各个变量

  • 每个变量一行，旁边有对应取值的刻度线。

  • 把所有变量的分数加起来，落在这一行的某个位置。

  • 底部：预测概率（如1年生存率）

  • 总分可以对应到一个概率，比如“1年生存率”

4.4.6 校准曲线rms::calibrate()

评估预测模型、在预测生存概率方面的校准性能。

黑色实线：表示预测生存概率与实际观察生存比例之间的关系。这是校准曲线的核心部分，反映模型的预测准确性。

总结

  • 数据准备与变量重编码：用 mutate() 将 status 和 sex 重编码为 0/1，符合生存分析格式

  • Cox模型拟合：coxph(Surv(time, status) ~ 变量, data=数据集)

  • 结果解读：关注 exp(coef)（风险比），正值风险升高，负值风险降低

  • 风险比例假设检验：用 cox.zph() 做 Schoenfeld 残差检验，判断模型假设成立性

  • 生存曲线与可视化：survfit() + ggsurvplot() ，ggforest() , rms:nomogram(), rms::calibrate()
