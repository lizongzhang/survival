3.1 什么是Kaplan-Meier 分析？

  • Kaplan-Meier 分析: 一种非参数生存分析方法，用来估计在不同时间点上，事件没有发生的概率。

  • 由 Edward Kaplan 和 Paul Meier 在 1958 年提出，是生存分析的基础工具。

  • Kaplan-Meier曲线：横轴是“时间”，纵轴是“生存概率(事件没有发生的概率)”，展示随着时间推移，事件“还没发生”的概率如何变化。

Kaplan, E. L., & Meier, P. (1958), Nonparametric estimation from incomplete observations, Journal of the American Statistical Association*, 53(282), 457–481. 🔗 DOI: 10.2307/2281868

Kaplan-Meier核心思想

  • Kaplan-Meier 分析:每当一个事件（如死亡）发生时，Kaplan-Meier 就更新一次“存活的概率”，并将它们连续相乘，逐步绘出生存曲线。

  • 优势：

    • 无需假设分布形式

    • 能处理右删失数据

    • 可用于组间比较（如治疗组 vs 对照组）

Kaplan-Meier曲线的特征

  • Kaplan-Meier曲线：随着时间推移，事件“还没发生”的概率如何变化。

  • 特征

    • 从高到低：曲线从1（100%存活）开始，随着时间推移下降，最终趋近0（所有事件发生）。

    • 阶梯状：每次有人去世，曲线会“跳一下”下降一点，反映事件发生。

    • 考虑了删失

Kaplan-Meier分析的意义

  • 可视化生存概率变化: 展示随着时间推移，事件“还没发生”的概率如何变化。

  • 有效处理随访过程中出现的删失（censoring）数据，Kaplan-Meier分析能充分利用这些不完整信息，提高结果的可靠性。

  • 比较组间差异：比较不同人群、不同治疗方法的生存概率的差异是否显著(log-rank检验)

  • 生存分析的起点，探索性分析，作为Cox回归等更复杂模型的前置分析步骤，帮助理解数据的初步分布和趋势。

生存函数的特征

  • \(S(0) = 1\)：起点时刻所有个体尚未发生事件；

  • \(S(t)\) 是非递增函数，随着时间推移，生存概率不会上升

  • 长期生存概率趋近于 0 或某个稳定值

    • 最终所有个体都发生了事件（如全部死亡、全部失效）

    • 有一部分个体在研究期间永远不会发生目标事件（部分病人痊愈，信贷分析中有些客户从不违约）

Kaplan-Meier分析局限性

  • 只能处理单因素分析

    • 如果想同时分析比如年龄、性别、治疗方式等多个因素对生存的影响，就需要用到Cox回归等方法。

  • 事件类型单一

    • 若同时存在多种类型的结局事件（比如死亡和失访、不同死因），需要用到竞争风险（Competing Risks）等模型。

  • 假定删失是无偏的

    • Kaplan-Meier分析假设删失数据与最终事件无关。如果删失与结局有关（比如身体状况差的人更容易失访），结果可能有偏。

Kaplan-Meier分析局限性

  • 要求样本量足够

    • 若随时间推移，样本量迅速减少（如大量删失），后期的生存率估计会非常不稳定、可信度下降。

  • 不能直接估计风险率

    • Kaplan-Meier关注的是“生存概率”，而不是“风险率”（hazard ratio），无法像Cox回归等方法量化风险差异。

3.2 一个简单的例子

× 事件发生（event = 1），如死亡、再就业、信件送达等。

● 删失（event = 0），表示观察期结束但事件尚未发生。

计算生存概率

\[ \hat{S}(t) = \prod_{i: t_i \leq t} \frac{n_i - d_i}{n_i} \]

\[ \hat{S}(2) = \frac{5 - 0}{5} = \frac{5}{5} = 1 \]

\[ \hat{S}(3) = \frac{4 - 0}{4} = \frac{4}{4} = 1 \]

\[ \hat{S}(4) = \frac{4 - 2}{4} = \frac{2}{4} = \frac{1}{2} = 0.5 \]

\[ \hat{S}(5) = \frac{1}{2} \cdot \frac{2 - 1}{2} = \frac{1}{4} = 0.25 \]

\[ \hat{S}(6) = \frac{1}{4} \cdot \frac{1 - 0}{1} = \frac{1}{4} = 0.25 \]

3.3 survminer

lung数据集简介

lung是survival包的内置数据集，包含228名肺癌患者的生存数据，主要变量包括：

  • inst：医疗机构编号

  • time：生存时间（天）

  • status：生存状态。1 = 删失（censored），2 = 死亡（event

  • age：年龄（岁）

  • sex：性别, 1 = 男，2 = 女

  • ph.ecog：ECOG（医生评估的体能评分），评分从 0（无症状）到 4（卧床）

  • ph.karno：医生评估Karnofsky评分, 0–100, 数值越高表示功能越好

  • pat.karno：患者评估Karnofsky评分

  • meal.cal：每餐摄入热量 (calories)

  • wt.loss：最近 6个月内体重下降的数值(磅)

3.3.1 绘制KM曲线

第1步：创建生存对象survial object

library(survival) Surv(time, status)

  • time：一个数值向量，表示每个观测对象的生存时间（如观察到死亡的时间，或随访截止时未死亡的时间）

  • event：一个二值（0/1）向量，表示该时间点是否发生了事件：

    • 1 表示事件发生（如死亡）

    • 0 表示删失（如随访结束时未发生事件）

  • 创建生存对象: 把“时间”和“事件状态”联合起来，所有生存分析建模函数（如survfit()、coxph()等）都要求第一个参数是 Surv() 生成的对象

  • Surv()可以明确告诉R哪些是删失、哪些是已发生事件

3.3.7 Log-rank检验

log-rank 检验两组或多组人的生存曲线是否存在显著差异。

如果 P 值 < 0.05，说明两组生存曲线差异显著

如果 P 值 > 0.05，说明差异步显著

rmst2() 需要指定一个截断时间点 tau，用于计算 RMST 和 RMTL。没有显式指定 tau（即 tau = NULL），函数自动选择了默认值 965天（数据中最大生存时间或接近最大值的合理时间点）

总结：女性在 965 天内的生存时间显著高于男性，损失时间显著低于男性，p值均小于 0.05。

实际应用： 临床研究：RMST 是生存分析的直观指标，比传统风险比（hazard ratio）更易解释，适合比较治疗效果或组间差异。

报告结果：可报告女性在 965 天内的平均生存时间比男性多约 132 天（p = 0.001），并用置信区间支持结论。

调整 tau：如果 965 天不适合你的研究（例如，想分析 1 年生存），可设置 tau = 365。
